# New organisation recording walkthrough

Prepared 17 October 2026. Leave MTG and QAHE unchanged.

1. Sign in as owner. Show the organisation directory and actual connection statuses.
2. New organisation: enter your presentation organisation name and choose Expense approval.
3. Modules: enable Expenses, Documents, Tasks, Notifications and Reporting. Save.
4. Configure: save organisation details and operational rules. Invite an organisation administrator; accept the invitation in a separate browser profile. Never record passwords or invitation tokens.
5. As organisation admin, use Records / Data Integration Centre to upload a separate test CSV or XLSX containing Title, Expiry and Category columns. Preview the file, map those columns, choose Document and import. Inspect saved documents. A local upload is a file import; it does not establish a live cloud connection.
6. Invite an employee and a manager with separate email identifiers. Accept each invitation and set individual passwords.
7. Expense rules: select Test mode, GBP, Travel category, threshold 100 and the invited manager. Save and run the configuration test. Complete onboarding tests and activate.
8. Sign in as employee. Submit a GBP 45 Travel expense with the test receipt supplied separately in the presentation kit. Copy the request ID.
9. Sign in as the assigned manager. Find that ID, approve with a comment and save.
10. Sign in as organisation admin. Expense reports → Test: show the saved decision, totals, filters and CSV/Excel export. Show users, documents and organisation activity.
11. Owner overview: show organisation/module management and aggregates. Detailed client records require the organisation admin to grant owner record access under operational rules. Company finances is a separate owner-only ledger.
12. After recording, owner → Organisations → Archive the newly created workspace. Show it under Archived organisations and optionally restore it. Restore leaves it inactive. Archiving retains records; it is not permanent deletion.

External Excel/Teams/Sheets delivery must remain Not connected until a real provider test succeeds. The approval above is the working internal OperaOS process. Use separate browser profiles for simultaneous roles; tabs share the session cookie.
